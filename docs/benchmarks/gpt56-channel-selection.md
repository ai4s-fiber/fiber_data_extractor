# GPT-5.6 通道选择记录

更新时间：2026-07-26

## 结论

- 默认通道：`gpt-5.6-luna`
- 批处理备选：`gpt-5.6-sol`
- 不作为默认通道：`gpt-5.6-terra`

三个通道都通过同一套 MinerU Cloud + strong/holistic + Stage 2 链路测试，模型可以通过项目配置或批处理参数显式切换。默认仍然保留 `gpt-5.6-luna`，不会把模型名硬编码到已有项目记录中。

## 三通道比较

测试输入为 `E:\数据\创智的paper` 中抽出的三篇研究论文，三次比较使用相同运行参数和已生成的 MinerU 解析产物；质量分数是当前系统的候选完整性代理指标，不等同于人工金标准准确率。

| 通道 | 总耗时 | 三篇候选数 | 质量代理分数 |
| --- | ---: | ---: | ---: |
| `gpt-5.6-luna` | 280.2 s | 26 / 15 / 36 | 0.9308 / 1.0000 / 0.8667 |
| `gpt-5.6-terra` | 304.7 s | 38 / 15 / 44 | 0.7809 / 0.9600 / 0.9045 |
| `gpt-5.6-sol` | 300.9 s | 26 / 15 / 34 | 0.9308 / 1.0000 / 0.8941 |

Gold 子集上的总体表现中，`luna` 和 `sol` 的单位与证据覆盖较稳定；`terra` 在样品目录为空时曾触发完整原子回退，造成候选膨胀和样品归属下降。`sol` 保留为备选，是因为它在部分论文上的过程/结构覆盖较好，但此前 smoke 测试出现过空结果，不适合直接取代默认通道。

## 空目录保护复测

为处理 `terra` 暴露出的长任务风险，强模式新增了“样品目录空结果一次小窗口重试”。它不会重新提交 MinerU，也不会重复成功的性能窗口；重试仍为空时才进入原有原子 Stage 1 回退。

同一篇论文的定向复测结果：

| 指标 | 旧 terra 记录 | 本次定向复测 |
| --- | ---: | ---: |
| 总耗时 | 84.8 s | 63.9 s |
| 候选数 | 38 | 26 |
| 质量代理分数 | 0.7809 | 0.9308 |
| LLM 调用数 | 29 | 5 |
| Stage 2 调用数 | 19 | 1 |

本次定向复测的首次样品目录调用直接成功，没有实际触发 retry stage；上表不能把全部改善归因于重试，因为网关模型输出具有随机性。新增重试路径通过强制空响应的单元测试验证：最多执行一次 `holistic_samples_retry`，仍为空后正常返回并交给现有回退链路。

## 运行配置

默认配置为：

```text
DEFAULT_LLM_MODEL=gpt-5.6-luna
LLM_DEFAULT_REASONING_EFFORT=low
STRONG_HOLISTIC_CATALOG_RETRY_ENABLED=true
STRONG_HOLISTIC_CATALOG_RETRY_MAX_CHARS=8000
STRONG_HOLISTIC_CATALOG_RETRY_MAX_TOKENS=1800
```

需要对照测试时，可在项目设置或批处理命令中显式使用 `gpt-5.6-sol` 或 `gpt-5.6-terra`。PDF 解析仍固定走成熟的 MinerU Cloud，不在 LLM 通道切换时重复实现解析逻辑。

## 残余风险

1. 当前代理质量分数不能替代人工金标准；正式批量抽取仍应抽样复核样品归属、表格行列映射和关键性能值。
2. GPT 网关的限流、超时和模型侧输出波动仍会影响单篇耗时；系统会保留阶段级指标，并按失败阶段回退。
3. `gpt-5.6-terra` 可以显式用于对照实验，但不建议作为准确性优先批处理的默认通道。
